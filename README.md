AI Office Assistant (Multi-Agent Workflow)

0x01 项目定位

本项目是一个基于 顺序多智能体编排 (Sequential Multi-Agent Orchestration) 架构的办公自动化原型。它通过解耦“规划、创作、摘要、验证”四个核心环节，模拟了企业级 AI 应用处理复杂任务的标准化流程。

0x02 核心架构

项目拒绝“单体式 (Monolithic)”脚本，采用模块化 Agent 设计：

Planner Agent: 任务解构与优先级定义。

Writer Agent: 基于规划生成的逻辑化文本构建。

Summarizer Agent: 信息熵压缩与核心要点提取。

Validator Agent: 输出质量对标与合规性静态检查。

0x03 快速启动

1. 环境初始化

确保已安装 Python 3.9+ 环境，执行以下命令安装依赖：

pip install -r requirements.txt


2. 启动应用

streamlit run app.py


0x04 技术优势

关注点分离 (SoC): 每个 Agent 独立文件存储，便于接入不同的 LLM 后端（如 GPT-4, Claude 等）。

可观察性 (Observability): 实时日志流展示，透明化 AI 思考过程。

轻量化: 无重型框架依赖，核心代码逻辑清晰，适合二次开发。
